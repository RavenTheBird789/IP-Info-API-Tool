# IP-Info-API-Tool
Python program that uses the baseline free API for ipinfo.io to pull information about a given IP address and return it to the user

To install, simply type "git clone " in your terminals command line

To run, simply type "python3 ip_info.py" in your terminals command line or use the alias command to create a shortcut to run the program in your terminal such as "alias ip="python3 ip_info.py""
